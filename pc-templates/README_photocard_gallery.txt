Files included:
- PhotocardGallery.jsx
- cards.json

Usage:
1. Put cards.json into your React app's public/ folder.
2. Import PhotocardGallery.jsx into App.jsx and render it.
3. Keep adding photocard entries to cards.json using the same shape.

Suggested card fields:
- id
- name
- release
- group
- idol
- albumName
- albumVersion
- image
- tags
- source
- notes
